# radiofm.rs 📻

[![Built With Ratatui](https://img.shields.io/badge/Built_With_Ratatui-000?logo=ratatui&logoColor=fff)](https://ratatui.rs/)

![demo](https://raw.githubusercontent.com/Kazooki123/radiofm.rs/refs/heads/main/demo.png)

An application that lets you listen to Radio Stations in the terminal, whether that'd be from the Internet or using a **RTL-SDR** dongle device to catch FM (Frequency Modulation) signals from your PC!

It has the features that any ordinary Radio FM app has built-into phones.

> [!IMPORTANT]
> This project is still in its' early stage, bugs or missing components may happen, and i'm still making this terminal application fixed and stable as possible.

## Setup

Prerequisites:

- USB **RTL-SDR** dongle

```bash
cargo build --release --features hardware
```
