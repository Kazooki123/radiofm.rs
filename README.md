# radiofm.rs 📻

[![Built With Ratatui](https://img.shields.io/badge/Built_With_Ratatui-000?logo=ratatui&logoColor=fff)](https://ratatui.rs/)

An application that lets you listen to Radio Stations in the terminal, wether that'd be from the Internet or using a **RTL-SDR** dongle device to catch FM (Frequency Modulation) signals from your PC!

## Setup

Prerequisites:

- USB **RTL-SDR** dongle

```bash
cargo build --release --features hardware
```
